  • EHR마다 다른 입력 방식을 어댑터로 분리하고 환경별 회귀 테스트를 추가해 문장 중복과 누락 방지

Population Health 데이터 파이프라인

  • 브라우저에서 처리하던 FHIR 데이터 수집과 캐시를 서버로 옮기고 검사, 투약, 임상 노트를 공통 포맷으로 정규화
  • FHIR·C-CDA 수집 경로를 통합하고 환자 목록 수집, 데이터 정규화, 조건 판정을 연결해 여러 환자를 일괄 평가할 수 있는 처리 흐름 구축
  • 동일 임상 데이터로 기존 웹 앱과 신규 파이프라인 결과를 교차 검증하고, 환자별 작업을 분리해 부분 실패가 전체 처리로 전파되지 않도록 처리

AI 임상 제안 검토

  • AI 임상 제안을 문장별로 수락·거절·수정하고 선택한 내용만 EHR에 반영하는 기능을 MVP로 시작해 서비스에 적용
  • 검토 상태를 세션에 보존해 재접속 후에도 작업을 이어갈 수 있도록 하고, 복원 과정의 중복 AI 요청·이벤트 실행 방지
  • Structured Outputs로 비정형 임상 문서를 typed data로 변환해 계산과 조건 판정에 재사용
  • 여러 LLM 공급자를 공통 인터페이스로 묶어 모델 교체가 기존 기능에 영향을 주지 않도록 설계
