  • C-CDA 파서를 추가해 외부 기관의 임상 문서를 FHIR 데이터와 동일한 내부 형식으로 정규화하고, 문서 유형을 LOINC 코드에 매핑

  • 로그의 환자 식별자를 작업 ID로 대체하고 FHIR URL의 식별자를 마스킹해 의료 데이터 파이프라인의 운영 로그에서 PHI 노출을 방지

Epic / SMART on FHIR 연동

  • Epic SMART on FHIR의 launch·OAuth·token 흐름을 코드 레벨로 분석하고, 인증 이후 브라우저에서 수행하던 Epic FHIR 조회를 서버·Lambda로 이관. FHIR client와 credential 처리 경로를 공통화
  • 사용 중인 Epic SMART 연동에서 refresh token이 발급되지 않는 제약을 고려해 access token 만료 시간을 검증하고, 잔여 시간이 10분 미만이면 배치를 시작하지 않도록 사전 차단
  • 환자 목록을 Epic Schedule API로 우선 조회하고 실패 시 FHIR 기반 조회로 전환하는 fallback을 구성해 Epic 환경의 환자 데이터 조회 경로를 안정화
  • DocumentReference와 분리된 임상 노트 본문을 FHIR Binary Resource에서 조회하는 경로를 추가하고, Binary 조회 과정의 외부 redirect를 EHR 서버 기준으로 제한
  • AI 처방 제안을 팀별 Epic 오더 카탈로그와 대조해 추천 목록을 생성하고, 의료진 확정 시 Epic AGL 채널을 통해 실제 오더로 전달하는 기능을 구현
